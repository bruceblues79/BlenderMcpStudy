# STARTER — Blender MCP 项目向导

## 触发条件

- 新建或初始化一个 Blender MCP 项目
- 需要为新项目编写或修改 `AGENTS.md`
- 需要接入、验证或排查 `mcp-for-blender`

## 第一步：铺底资产与环境

1. 建立 `scenes/`、`previews/`、`render/` 三个目录，再把 `assets/ref_human.blend` 和 `assets/je_gray_02_1k.exr` 复制到项目根目录，已存在则跳过
2. 读 `references/MCP_SETUP.md`
3. 调 `get_addon_status` 确认 addon 在线
4. 调 `get_scene_info` 确认当前文件与对象列表

连接失败时按 MCP_SETUP 的故障表处理，不要跳过直接开工。

## 第二步：向导提问

逐项提问，**每一项都必须给出默认值**，用户回答"默认"或直接确认即采用默认。一次最多问 4 项，避免刷屏。

| # | 项目 | 默认值 | 备选 |
|---|---|---|---|
| 1 | 项目名 | `theme` | 自定义 |
| 2 | 建模面 | 四边面 | 三角面 |
| 3 | 比例参照 | 1.8m 人形（`ref_human`） | 1m 立方体 / 无 |
| 4 | 缩放比 | 1:1 | 1:10 等 |
| 5 | 渲染引擎 | EEVEE | Cycles |
| 6 | 环境光 | `je_gray_02_1k.exr` | 纯色 / 无 |
| 7 | 额外灯光 | 不加 | 允许 |
| 8 | Film 透明 | 开 | 关 |
| 9 | 视窗焦距 | 24mm | 35mm / 50mm |
| 10 | 目标平台 | pico-spatial-sdk | 通用 |
| 11 | 文件命名 | `theme_<内容>_YYMMDDHHMM.blend` | 自定义 |
| 12 | 风格来源 | LLM 根据描述自行发挥 | 参考图 / 预设组 |
| 13 | 倒角策略 | LLM 自由发挥，不限定尺寸 | 统一倒角 |
| 14 | 破损程度 | 严重侵蚀 | 轻微磨损 / 完好 |
| 15 | 材质 | 白模（默认 pbr 素模） | 白模 + Poly Haven 贴图 |

比例参照与缩放比必须联动，且只写一种口径：1:1 时参照物保持 `1.8` 米；1:10 时写 `0.18` 米。不要同时写真实尺寸和折算尺寸。

## 第三步：风格来源

- **默认（LLM 自行发挥）**：从用户的一句话描述里归纳 3–5 个风格关键词，直接写入 `风格` 字段，不再追问细节。
- **参考图**：先输出解读结果并让用户确认，确认后才写入 STYLE 段。固定输出五项：
  1. 风格关键词（3–5 个）
  2. 形体特征（轮廓、体量、比例）
  3. 破损模式（缺角、裂缝、侵蚀面、边缘抖动）
  4. 材质倾向（粗糙度、金属度、颜色）
  5. 明确不做的效果

不要在图上看不出来的地方补细节。

## 第四步：材质

- **白模（默认）**：只写默认 pbr 素模，颜色默认，粗糙度与金属度可调，不创建任何贴图。
- **Poly Haven**：白模验证通过后，用 `search_assets` 检索 Poly Haven 资产、`import_asset` 导入并上贴图。AGENTS.md 中必须写明"先白模验证，再上贴图"的先后顺序。

## 第五步：生成 AGENTS.md

- `MUST DO FIRST` 一字不改，置于文件最前
- 其余段落按 `references/AGENTS_TEMPLATE.md` 填充
- 未提问的项写默认值，不写空、不臆造
- 数值只写一处；命名规则里的项目名必须与第 1 项一致
- 选"不设"的可选项整行省略，不要输出"不设"
- 已存在 `AGENTS.md` 时先备份为 `AGENTS.md.bak`，不直接覆盖

## 第六步：交付

汇报三件事：

1. 本次采用的默认值清单
2. 仍需用户确认的项
3. 生成的文件路径
